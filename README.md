# FavoritSerier

A small SQL Server database about my favourite TV series, built in SSMS as a school project.

## What it contains
- A table `SerieInfo` with 31 series: live action, anime and cartoons
- Columns: title, type, genre, start date, seasons, episodes, ranking, description and whether the series is ongoing

## How to run it
1. Open `FavoritSerier.sql` in SQL Server Management Studio
2. Run the whole script once. It creates the database, the table and the data
3. Try the queries at the end of the file

## What I practised
`CREATE DATABASE`, `CREATE TABLE`, `INSERT`, `SELECT`, `WHERE`, `ORDER BY`, `CASE`
